# NNNN: the decision in one line

Status: accepted, in #N.

Copy this file to `docs/decisions/NNNN-short-name.md`, take the next free
number, and delete the guidance under each heading as you answer it. Headings
you have nothing to say under come out; a heading kept with "n/a" under it reads
as an answer and is not one.

## Decision

What was decided, in the present tense, as a statement rather than a
recommendation. Write it before the first file that depends on the answer. The
code will later show what was chosen and nothing will show what was rejected or
why, which is the whole reason this file exists.

Where the decision is about what an artefact is made of, say so here. That check
is made per artefact and never carried over from the last one, so a record that
only names the choice has left out the part that was actually decided.

## What forced it

The constraints that were already fixed before anyone had an opinion. Each one
with the evidence, and where the evidence is a number, the command that produced
it, run against the thing itself rather than against the nearest field that
answers quickly.

## What it costs

Costs that are not mitigated are still written here. A record that lists only
the costs it has an answer for is an argument rather than a record.

## What is rejected

The alternatives that were considered and what each one was rejected for. An
alternative dismissed without a reason is one that comes back in six months with
nobody able to say why it lost.

## What this record does not measure

The things a reader might reasonably expect to be quantified here and which are
not, named rather than left out, so that an absence of a number is readable as
an absence rather than as a small number.

## What would reverse this

The measurement or the change in the world that makes the decision wrong. A
decision with no reversal condition cannot be revisited on evidence, only on
mood.

Reversal is a new record, not an edit to this one.
